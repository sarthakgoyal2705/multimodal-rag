# BioPath RAG: Multimodal Scientific Workbench

BioPath RAG is an advanced Multimodal Retrieval-Augmented Generation (RAG) application designed to act as an AI-powered research assistant. It helps researchers, biologists, and clinicians make sense of complex biological literature, clinical trials, and signaling pathway diagrams by providing instant, accurate, and fully cited answers.

## 🚀 Features

- **Multimodal Document Understanding**: Seamlessly processes both text and complex visual data (e.g., pathway diagrams, charts, chemical structures) from uploaded PDF documents.
- **Accurate Citations**: Every answer generated by the assistant is grounded in the source documents and provides exact citations (including page numbers and text snippets) to completely eliminate hallucinations.
- **Minimalist, Professional UI**: Built with a stunning, distraction-free minimalist theme (slate gray and cool gray palette) to keep the focus on the science.
- **Lightning Fast Responses**: Powered by Groq's high-performance inference engine for near-instant text generation.

## 🛠️ Architecture & Tech Stack

This project is split into a highly scalable Python backend and a modern React frontend:

### Backend (Python/FastAPI)
- **Framework**: [FastAPI](https://fastapi.tiangolo.com/) for high-performance API routing.
- **RAG Orchestration**: [LlamaIndex](https://www.llamaindex.ai/) for document chunking, indexing, and vector search.
- **LLM Engine**: [Groq](https://groq.com/) API running `llama-3.1-8b-instant` for ultra-fast generation.
- **Embeddings**: Google Gemini (`models/embedding-001`) for high-quality text vectorization.
- **Storage**: In-memory VectorStore for rapid retrieval (extensible to Pinecone/Qdrant).

### Frontend (Next.js/React)
- **Framework**: [Next.js](https://nextjs.org/) (App Router) with React 19.
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/) using modern `@theme` variable mapping for the custom minimalist palette.
- **Icons**: Lucide React.

## ⚙️ Local Development Setup

### Prerequisites
- Python 3.10+
- Node.js 18+
- Groq API Key
- Google Gemini API Key

### 1. Backend Setup
Navigate to the root directory and set up your virtual environment:

```bash
python -m venv venv
# Windows:
.\venv\Scripts\activate
# Mac/Linux:
source venv/bin/activate

pip install -r requirements.txt
```

Create a `.env` file in the root directory and add your keys:
```env
GROQ_API_KEY=your_groq_api_key_here
GEMINI_API_KEY=your_gemini_api_key_here
```

Start the FastAPI server:
```bash
python server.py
```
*The server will run on `http://localhost:8000`*

### 2. Frontend Setup
Open a new terminal and navigate to the `frontend` directory:

```bash
cd frontend
npm install
npm run dev
```
*The web app will be available at `http://localhost:3000`*

## 💡 Usage

1. Open the web app and click **Launch Workbench**.
2. Upload biological research papers or clinical reviews (PDF format).
3. The backend will automatically extract the text, analyze figures, and build a local vector index.
4. Use the chat interface at the bottom to ask questions about pathways, mutations, or specific figures in your documents!
